## Key Technical Details

### AC7 — Archive Flow Blocked (Deferred)

Testing AC7 revealed that Migration 0193's constrained trigger **blocks all UPDATEs** except `superseded_by_snapshot_id` NULL→non-NULL. The trigger requires:

```sql
AND OLD.status <=> NEW.status        -- status cannot change
AND OLD.archived_at <=> NEW.archived_at  -- archived_at cannot change
AND OLD.archive_version <=> NEW.archive_version  -- cannot change
```

Setting `status='ARCHIVED'`, `archived_at`, or `archive_version` via UPDATE would be rejected. No archive service method exists. AC7 is deferred to a future story that can implement archive-specific service logic with trigger bypass or a different data model.

### Chain Traversal Helper

Added a reusable `getSnapshotChain()` helper at the top of the describe block — walks `superseded_by_snapshot_id` pointers for any company+as_of_date. Used by AC1, AC2, AC3, AC8.

### AC6: Concurrent Manual Snapshots

Unlike the existing concurrent auto-snapshot test (which tests idempotent duplicate prevention), this test fires two distinct manual snapshots (`autoGenerated: false`) — each must produce a different version number. The service's `FOR UPDATE` lock + retry loop handles the concurrency correctly.
