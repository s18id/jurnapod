## Key Technical Details

### Service Fix: Broadened Idempotency Guard

**Before (lines 257–264):**
```typescript
if (isAutoGenerated && previous && previous.autoGenerated && previous.inputsHash === inputsHash) {
  return previous;
}
```

**After:**
```typescript
if (isAutoGenerated && previous && previous.inputsHash === inputsHash) {
  return previous;
}
```

The `inputsHash` is a deterministic SHA-256 of: `{company_id, as_of_date, timezone, configured_account_ids, account_source, ap_subledger_balance, gl_control_balance, variance}`. If a manual snapshot captured identical financial state, the auto-snapshot's hash matches → no version bump.

### AC1 Race Simulation (Sequential)

The test simulates the E51-A1 race condition sequentially:
1. Manual snapshot created first (simulates user during post-close gap)
2. Auto-snapshot fires (simulates fiscal close auto-trigger after gap)
3. Both return the **same snapshot ID**
4. Exactly **1 row** in DB for that company+date
5. Audit trail shows **CREATED** (not RECALCULATED)

### AC4 CSV Correctness

Verifies CSV export for both current and superseded snapshots:
- `snapshot_id` and `snapshot_version` match expected values
- `ap_subledger_balance`, `gl_control_balance`, `variance` non-empty
- `status = 'ACTIVE'` for non-archived snapshots
- Superseded snapshot (v1) exports with its own data
